# Is It Full? admin panel

The Next.js admin interface for machines, reports, users and feedback.

Run these commands from `admin-panel/`:

```sh
cp .env.example .env.local
npm ci
npm run dev
```

`.env.example` sets `NEXT_PUBLIC_API_URL=http://localhost:8080`; change it for your backend.
Open [the login page](http://localhost:3000/login).
See [CONTRIBUTING.md](../CONTRIBUTING.md) for backend setup and checks.
